## About Me

I'm a **full-stack developer who leans backend**. I like the part of a product nobody sees: clean APIs, solid data models, and databases that don't fall over. On the front end I work with React and Next.js to ship the interface on top.

- **Now:** building a data platform that digitizes a company's internal workflow, and contributing to **NCT Hub**, the official website of RMIT Neo Culture Tech
- **Learning:** backend design with Postgres & Supabase: schemas, auth, row-level security
- **Looking for:** my first **Software Engineering internship** (backend / full-stack), remote-international or Vietnam-based
- **Ask me about:** Next.js, Express APIs, Supabase
